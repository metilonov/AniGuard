# Профиль пользователя AniGuard

Добавлено в Mini App:

- кнопка ручного переключения светлой/тёмной темы слева от меню `⋮`;
- меню аккаунта: Профиль, Настройки, Реклама, FAQ;
- отдельный пользовательский профиль с Telegram-аватаром, именем, ID и сроком использования бота;
- AniCoin-кошелёк;
- статистика в порядке: Рейтинг | Уровень аккаунта, Игровой уровень | Репутация;
- золотой ник для Premium и серо-синий для обычного аккаунта;
- отдельные SVG-иконки в `app/static/icons/profile/`;
- расширенный `/api/me`, который отдаёт баланс, Premium и рассчитанную статистику.

## Формулы статистики

Статистика вычисляется сервером из существующих данных, без добавления новых столбцов:

- уровень аккаунта: активность, количество бесед и XP;
- игровой уровень: общий XP;
- рейтинг: XP, сообщения, беседы, предупреждения и штрафные баллы;
- репутация: 100 минус предупреждения и штрафные баллы.

Баланс берётся из `user_wallets`. Если кошелёк ещё не создан, используется сумма AniCoin из членств пользователя в группах.
