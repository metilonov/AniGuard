# AniGuard

Telegram-бот для модерации со встроенной Mini App, глобальной панелью владельца, конструктором кастомных команд, игровыми командами и Premium через Telegram Stars.

## Основные возможности

### Модерация обычным русским текстом

Команды можно писать без сокращений времени вроде `30m` или `2h`:

```text
Мут @username 30 секунд флуд
Бан @username 7 дней реклама
Карантин @username 2 часа подозрение на спам
Запретить медиа @username 1 день
Запретить ссылки @username 1 неделю
Заблокировать команды @username 3 дня
```

Поддерживаются формы и сокращения:

```text
секунда, секунды, секунд, сек, с
минута, минуты, минут, мин, м
час, часа, часов, ч
день, дня, дней, д
неделя, недели, недель, нед
месяц, месяца, месяцев, мес
навсегда, бессрочно, постоянно
```

Можно составлять срок из нескольких частей:

```text
Мут @username 1 день 2 часа 30 минут флуд
```

Команды также работают ответом на сообщение:

```text
Мут 10 минут флуд
```

Если срок не указан, используется срок соответствующей команды из настроек группы. Изначально для временных наказаний установлено **7 дней**.

Причина определяется автоматически как весь текст после пользователя и срока. Перенос строки поддерживается:

```text
Бан @username
Флуд и реклама
```

Слово `за` и префиксы `причина:`, `причина —` необязательны.

### Глобальная панель владельца

Раздел отображается только Telegram ID из `ADMIN_IDS`, а доступ дополнительно проверяется на сервере.

Возможности:

- статистика пользователей, групп, Premium и блокировок;
- поиск пользователей и групп по ID, имени или username;
- выдача Premium на срок или навсегда;
- отзыв Premium;
- временная и постоянная блокировка доступа пользователя или группы;
- причина блокировки;
- глобальный журнал действий владельца.

Владелец AniGuard может открывать панели всех зарегистрированных групп.


### Постоянный реестр групп

- база SQLite находится в `/app/data/aniguard.db` и не удаляется при обновлении Bothost;
- существующая старая база из корня автоматически переносится в постоянное хранилище, если ещё доступна;
- при запуске бот повторно синхронизирует зарегистрированные группы, владельцев, названия и аватары;
- новые группы регистрируются через событие Telegram `my_chat_member`;
- в Mini App отображаются реальные аватары групп, а при их отсутствии — инициалы;
- аватар владельца админ-панели загружается из профиля `/admin` и сохраняется в `/app/data`.

### Панель управления группой

- все основные действия модерации;
- участники и внутренние роли AniGuard;
- отдельные сроки по умолчанию для мута, бана, карантина и ограничений;
- антифлуд, CAPTCHA, фильтры ссылок и слов;
- жалобы и журнал модерации;
- правила автомодерации;
- RP-команды;
- кастомные Premium-команды;
- игровые команды, XP и AniCoin;
- управление Premium.

### Обновлённая Mini App

Mini App переработана как мобильная панель в стиле Telegram и подключена к существующему FastAPI API проекта.

- свободное переключение между группами с отдельными настройками;
- нижняя навигация: главная, модерация, команды и профиль группы;
- уникальные SVG-иконки для функций и явные состояния нажатия;
- профиль группы с участниками, владельцем, правилами, приветствием, CAPTCHA и Premium;
- участники, роли, жалобы, журнал действий, RP, правила и игровые команды;
- конструкторы кастомных и игровых команд;
- глобальная панель владельца AniGuard;
- расширенная автомодерация с Premium-маркировкой и серверной проверкой доступа;
- тема Telegram, safe-area, BackButton, haptic feedback и адаптивная вёрстка;
- поиск по разделам и настройкам выбранной группы.

Premium-настройки нельзя включить только обходом интерфейса: сервер также проверяет подписку группы перед сохранением.

### Новые участники и CAPTCHA

- автоматическая смысловая CAPTCHA: изображение и клавиатура 3×3 со смайлами;
- отдельные настройки для каждой группы: время, попытки, действие при провале и набор изображений;
- до успешной проверки участник находится в карантине;
- после прохождения CAPTCHA бот снимает ограничения и отправляет приветственное сообщение;
- приветствие поддерживает текст, переменные и фотографию;
- правила группы редактируются из Mini App и доступны командой `/rules`.

### Участники, владелец и Premium

- список известных боту участников с аватаром, полным именем, Telegram ID и username;
- карточка участника с ролью, предупреждениями, статистикой и действующими ограничениями;
- реальные действия: блокировка, удаление, изменение внутренней роли;
- карточка владельца группы;
- отдельная страница Premium со сроком, источником подписки, возможностями и продлением через Telegram Stars;
- Premium владельца автоматически распространяется на созданную им группу до окончания его подписки;
- группе также можно купить собственный Premium независимо от владельца.

> Ограничение Telegram Bot API: бот не может запросить полный исторический список всех обычных участников произвольной группы. В таблице показываются администраторы и пользователи, которых AniGuard уже увидел при вступлении, сообщениях или действиях. Общее количество участников берётся непосредственно из Telegram.

### Кастомные команды модерации

Пример настройки:

```text
Название: Цукиёми
Триггер: цукиёми
Действие: Мут
Срок: 10 минут
Ответ: {admin} использовал {command} на {user}.
```

Использование:

```text
Цукиёми @username флуд
```

или ответом на сообщение:

```text
Цукиёми
флуд
```

Переменные ответа:

- `{admin}` — кликабельная ссылка на профиль администратора;
- `{user}` — кликабельная ссылка на профиль пользователя;
- `{command}` — название команды;
- `{duration}` — срок действия;
- `{reason}` — причина;
- `{chat}` — название группы.

Пользовательский Python-код не выполняется: действие выбирается из безопасного списка. После завершения Premium команды сохраняются в базе, но замораживаются до продления подписки.

### Игровые команды

Через Mini App можно создавать текстовые, случайные и наградные команды. Поддерживаются:

- несколько вариантов ответа;
- кулдаун;
- доступ для всех, проверенных участников, модераторов или администраторов;
- награды XP и AniCoin;
- переменные `{user}`, `{target}`, `{text}`, `{chat}`, `{xp}`, `{coins}`.

## Установка

Требуется Python 3.12+.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Пример `.env`:

```env
BOT_TOKEN=токен_от_BotFather
WEBAPP_URL=https://aniguard.example.com
DATA_DIR=/app/data
DATABASE_URL=sqlite+aiosqlite:////app/data/aniguard.db
ADMIN_IDS=[123456789]
RECOVERY_CHAT_IDS=[]
DEV_MODE=false
INIT_DATA_MAX_AGE=3600
HOST=0.0.0.0
PORT=3000
LOG_LEVEL=INFO
```

`ADMIN_IDS` принимает один ID, список в квадратных скобках или несколько ID через запятую.

Запуск:

```bash
python start.py
```

## Настройка на Bothost

Укажите:

```text
Главный файл: start.py
Порт веб-приложения: 3000
```

В переменных окружения должны совпадать:

```env
HOST=0.0.0.0
PORT=3000
WEBAPP_URL=https://ваш-домен.bothost.tech
```

После изменения переменных выполните пересборку и перезапуск. В логах должна появиться строка запуска Uvicorn на `0.0.0.0:3000`.

## Docker

```bash
cp .env.example .env
docker compose up -d --build
```

Mini App будет доступна на порту `3000`.

## Подключение Mini App

1. Разместите приложение на HTTPS-домене.
2. Укажите домен в `WEBAPP_URL`.
3. В BotFather задайте домен Mini App через `/setdomain`.
4. Добавьте бота администратором группы.
5. Разрешите удаление сообщений, блокировку пользователей, ограничение участников и управление приглашениями.
6. Отключите Privacy Mode через BotFather, если AniGuard должен видеть обычные сообщения и запускать изменённые текстовые команды без `/`.
7. Отправьте в группе `/panel`.
8. Откройте AniGuard в личном чате.

## Безопасность

- Telegram `initData` проверяется сервером;
- права администратора группы проверяются через Telegram API;
- глобальная панель защищена `ADMIN_IDS` на уровне API;
- кастомные команды не выполняют произвольный код;
- заблокированные пользователи и группы отсекаются middleware;
- настоящий `.env` и база данных исключены из Git;
- `DEV_MODE=true` разрешён только для локальной разработки.

Для локальной Mini App при `DEV_MODE=true`:

```text
http://localhost:3000/?dev_user_id=ВАШ_TELEGRAM_ID
```

## Новые маршруты панели

Проект теперь обслуживает два интерфейса на основном домене:

- `/panel` — панель управления беседами;
- `/admin` — закрытая панель владельца AniGuard.

Корневой маршрут `/` перенаправляет на `/panel`. Для запуска на Bothost используйте значения `WEBAPP_URL=https://aniguard.bothost.tech/panel` и `ADMIN_URL=https://aniguard.bothost.tech/admin`. Полная инструкция находится в `DEPLOY_BOTHOST.md`.


## Integrated store and owner panel

The current build includes server-side AniCoin purchases, the Premium case, advertising moderation and a persistent support chat. The owner panel exposes dedicated tools for pending advertising, support tickets, case history and wallet transactions. See `STORE_ADMIN_INTEGRATION.md` for the routes and payment flow.
