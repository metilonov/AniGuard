# AniGuard commands catalog v16

В проект добавлен единый каталог встроенных команд:

- 19 базовых команд модерации;
- 80 Naruto-команд с номерами 101–180;
- разделение на обычные и Premium-команды;
- русские и английские алиасы для базовой модерации;
- вызов с `/` и без `/`;
- пробелы, `_` и `-` взаимозаменяемы в названии команды;
- краткие ответы бота.

Примеры равнозначного синтаксиса:

```text
/ban @username
ban @username
бан @username

/расен_сюрикен @username
расен_сюрикен @username
расен сюрикен @username
```

## Ограничения Telegram

Telegram Bot API не предоставляет IP пользователей, не позволяет искать альтернативные аккаунты, блокировать человека на сторонних платформах или удалить и пересоздать существующий чат. Такие команды возвращают честное краткое сообщение либо выполняют ближайшее безопасное действие внутри AniGuard.

Команды массового удаления участников требуют владельца группы и явного слова `подтвердить`.
