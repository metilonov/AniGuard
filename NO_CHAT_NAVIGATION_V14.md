# Навигация без подключённых групп

Когда у пользователя нет доступных групп, нижняя навигация остаётся активной и показывает только:

- Магазин
- Аккаунт

После подключения первой группы автоматически становятся доступны:

- Главная
- Модерация
- Команды
- Группа
- Магазин
- Аккаунт

Групповые разделы защищены от открытия без подключённой беседы.
