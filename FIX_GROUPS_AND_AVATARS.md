# Исправление реестра групп и аватаров

## Что исправлено

- SQLite перенесён в постоянное хранилище Bothost: `/app/data/aniguard.db`.
- Старое значение `sqlite+aiosqlite:///./aniguard.db` автоматически перенаправляется в `/app/data`.
- При запуске бот повторно синхронизирует сохранённые группы, владельцев, названия и фотографии.
- Событие Telegram `my_chat_member` регистрирует группу сразу при добавлении бота или выдаче ему прав.
- В `/panel` и `/admin` отображаются реальные аватары групп.
- В `/admin` можно загрузить собственный аватар владельца; файл хранится в `/app/data/uploads/admin`.
- Фотографии приветствия теперь также хранятся в `/app/data/uploads` и не исчезают после обновлений.

## Переменные Bothost

```env
DATA_DIR=/app/data
DATABASE_URL=sqlite+aiosqlite:////app/data/aniguard.db
RECOVERY_CHAT_IDS=[]
```

Если старая база уже была удалена прошлым обновлением, после первого запуска отправьте `/panel` один раз в каждой существующей группе. После регистрации группы сохранятся постоянно.

Альтернативно можно временно указать известные ID групп:

```env
RECOVERY_CHAT_IDS=[-1001111111111,-1002222222222]
```

После успешной синхронизации эту переменную можно оставить или очистить.
