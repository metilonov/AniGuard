# Naruto MMO V5 — media UI update

Что добавлено:

- Все сгенерированные Naruto-изображения добавлены в `assets/naruto_ui/`.
- Для ключевых разделов меню включена отправка тематических фото вместо простого текста.
- Для экранов `home`, `profile` и `ready` добавлена анимированная GIF-карточка с индикаторами:
  - здоровье
  - чакра
  - энергия
  - опыт
- Полоски меняются динамически на основе текущих значений профиля.
- Обновлена логика `router.py`: callback-экраны открываются как новые медиа-сообщения с кнопками.

Основные файлы:

- `app/naruto_game/media.py`
- `app/naruto_game/router.py`
- `assets/naruto_ui/*`

Поведение:

- `profile/home/ready` -> GIF-анимация статов
- `inventory` -> картинка инвентаря
- `market/economy` -> картинка рынка
- `battle/arena` -> картинка боя
- `mission/story` -> картинка миссий
- `cards` -> картинка карточек
- `clan/social` -> картинка совета клана
- `world/*` -> картинка стратегической карты мира
