# AniGuard v18 — полный импорт команд из rp.txt

## Результат

- Источник RP/игровых действий: 300 строк команд.
- В проекте: 299 уникальных игровых команд.
- Команда №277 `найти_биджу` не дублируется, потому что такой вызов уже есть под №138.
- Модерация: все 180 Naruto-команд.
- Обычные команды модерации: 19 русских/английских базовых команд.
- Всего записей каталога модерации: 199.

## Синтаксис

Для игровых и модерационных команд работают варианты:

```text
/тобирама_водный_дракон @username
тобирама_водный_дракон @username
тобирама водный дракон @username
```

Для обычной модерации работают русские и английские вызовы:

```text
/ban @username
ban @username
бан @username
```

## Совпадения игровых и модерационных названий

Если одинаковое название есть в обоих каталогах, у модератора по умолчанию выполняется модерация. Игровое действие вызывается с префиксом:

```text
игра расенган @username
/игра_расенган @username
```

## Ограничения Telegram

Функции, которых нет в Telegram Bot API, не подделываются. Бот сообщает об ограничении либо применяет безопасный ближайший вариант. Например, скрытие сообщений одного пользователя только от остальных заменяется бессрочным мутом.
