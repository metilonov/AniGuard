# Подключение AniGuard к настоящему Telegram-боту

## Обязательные переменные окружения

```env
BOT_TOKEN=токен_от_BotFather
WEBAPP_URL=https://ваш-домен.example
DATABASE_URL=sqlite+aiosqlite:///./aniguard.db
ADMIN_IDS=[ваш_telegram_id]
DEV_MODE=false
HOST=0.0.0.0
PORT=3000
```

## Права бота в группе

Бот должен быть администратором с правами:

- удалять сообщения;
- блокировать и удалять пользователей;
- ограничивать участников;
- управлять приглашениями;
- закреплять сообщения — только если эта возможность будет использоваться.

Для обработки обычных текстовых сообщений и изменяемых команд без `/` отключите Privacy Mode у бота через BotFather.

## Mini App

1. Разместите проект на HTTPS-домене.
2. Укажите этот адрес в `WEBAPP_URL`.
3. Через BotFather задайте тот же домен для Mini App.
4. Запустите `python start.py`.
5. Добавьте бота в группу и отправьте `/panel`.

## Важное ограничение списка участников

Telegram Bot API не выдаёт боту полный исторический список обычных участников группы. AniGuard показывает администраторов и пользователей, которых бот уже увидел при вступлении, сообщениях или действиях. Общее число участников запрашивается у Telegram отдельно.

## Premium

Группа получает Premium одним из двух способов:

1. собственная подписка группы через Telegram Stars;
2. активная подписка создателя группы, которая наследуется группой до окончания Premium владельца.

Сервер проверяет Premium при сохранении Premium-настроек и редактировании основных команд, поэтому ограничение нельзя обойти только изменением интерфейса.
