# AniGuard

Готовый Telegram-бот-модератор с подключённой Telegram Mini App и оплатой Premium через Telegram Stars.

## Что реализовано

### Обычный функционал

- `/warn`, `/unwarn` — предупреждения.
- `/mute`, `/unmute` — ограничение сообщений.
- `/ban`, `/unban` — блокировка и разблокировка.
- `/purge` — удаление последних сообщений.
- `/slow` — программный медленный режим.
- `/lock`, `/unlock` — закрытие и открытие беседы.
- `/report` — жалобы ответом на сообщение.
- `/profile`, `/top`, `/topchats` — профили и рейтинги.
- антифлуд, фильтр ссылок, запрещённые слова, массовые упоминания;
- CAPTCHA для новых участников;
- до 5 правил модерации;
- до 25 пользовательских RP-команд;
- ранги, XP и AniCoin с возможностью полного отключения аниме-функций.

### Premium

## Архитектура

- `aiogram 3` — Telegram-бот и платежи Stars;
- `FastAPI` — API и раздача Mini App;
- `SQLAlchemy Async` — база данных;
- SQLite по умолчанию, PostgreSQL через Docker Compose;
- Mini App использует `Telegram.WebApp.initData`, которое проверяется сервером;
- бот и Mini App вызывают общий сервис модерации, поэтому действия и настройки синхронизированы.

## Быстрый запуск без Docker

Требуется Python 3.12+.

```bash
cd AniGuard
python -m venv .venv
source .venv/bin/activate      # Linux/macOS
# .venv\\Scripts\\activate     # Windows
pip install -r requirements.txt
cp .env.example .env
```

Заполните `.env`:

```env
BOT_TOKEN=токен_от_BotFather
WEBAPP_URL=https://ваш-домен.example
DATABASE_URL=sqlite+aiosqlite:///./aniguard.db
ADMIN_IDS=ваш_telegram_id
DEV_MODE=false
```

Запуск:

```bash
python start.py
```

## Запуск через Docker Compose

```bash
cp .env.example .env
# заполните BOT_TOKEN и WEBAPP_URL
# пароль PostgreSQL change_me замените одновременно в docker-compose.yml
docker compose up -d --build
```

## Подключение Mini App

1. Разместите проект на сервере с HTTPS.
2. Укажите публичный адрес в `WEBAPP_URL`, например `https://guard.example.com`.
3. Запустите проект. Бот сам установит кнопку меню `AniGuard` через `setChatMenuButton`.
4. В `@BotFather` задайте домен Mini App через `/setdomain`.
5. Добавьте бота в группу администратором.
6. Разрешите боту удалять сообщения, блокировать пользователей и ограничивать участников.
7. Отправьте в группе `/panel`.
8. Откройте личный чат с ботом и нажмите кнопку `AniGuard`.

Mini App показывает только те зарегистрированные беседы, где открывший её пользователь является администратором.

## Использование команд

Команды с целью удобнее отправлять ответом на сообщение:

```text
/warn причина
/mute 30m флуд
/ban 7d реклама
/quarantine 1h проверка аккаунта
/report оскорбление
```

Также можно передать ID или известный боту username:

```text
/mute @username 2h флуд
/ban 123456789 7d реклама
```

`/purge 25` удаляет до 25 последних сообщений. `/slow 15` включает задержку 15 секунд, `/slow off` отключает её.

## RP-команды

Команды создаются в Mini App. Поддерживаемые переменные:

- `{actor}` — автор команды;
- `{target}` — выбранная цель;
- `{text}` — текст после команды;
- `{chat}` — название беседы.

Пример:

```text
Команда: ударить
Ответ: {actor} ударил {target}
```

Пользователь отвечает на сообщение другого участника словом `ударить`, и бот публикует настроенный ответ.

## Telegram Stars

Mini App запрашивает у бэкенда ссылку счёта, затем открывает её через `Telegram.WebApp.openInvoice`. Бот проверяет `pre_checkout_query`, а после `successful_payment` продлевает Premium выбранной беседы. Для Stars используется валюта `XTR` и пустой `provider_token`.

## Безопасность

- Не доверяйте `initDataUnsafe`.
- Сервер проверяет подпись и срок действия `initData`.
- Перед каждым изменением настроек или наказанием повторно проверяются права администратора через Telegram.
- Платёж привязан к конкретному пользователю, беседе, тарифу и сумме.
- `DEV_MODE=true` предназначен только для локальной разработки. В этом режиме панель можно открыть как `http://localhost:8000/?dev_user_id=ВАШ_ID`.

## Важные ограничения Telegram

Бот должен быть администратором с необходимыми правами. Программный медленный режим реализован самим AniGuard: сообщения, отправленные раньше разрешённого интервала, удаляются. Это не меняет встроенный параметр Slow Mode в настройках Telegram-группы.
