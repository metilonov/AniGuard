# Встроенные игровые действия v17

- Добавлены 96 Naruto-команд действий.
- Поддерживаются `/команда`, `команда_с_подчёркиванием` и `команда с пробелами`.
- Для конфликтующих с модерацией названий модератор может принудительно вызвать игровую версию через `игра <команда>`.
- Команды разделены на обычные и Premium.
- Ответы используют реальные Telegram-ссылки на инициатора и цель.
